# Toric SCL Axis Planner — v0.2.0

日本語のStreamlitアプリ。教育・研究用の臨床未検証プロトタイプです。

**起動済みの旧版は app.py の差し替えで更新できます。** 詳しくは [更新手順](START_HERE_JA.md) を参照してください。

- 03の実測回転入力を削除。
- 01：S/C 0.25 D、Ax 5°。
- 02：S/C 0.25 D、Ax 10°。
- 04：S/C 0.01 D、Ax 1°。
- 数値欄はリスト選択・直接入力の両方に対応。指定刻みは計算時に検証し、自動では丸めません。
- 回転を0°とは仮定しません。装用前−装用後の乱視ベクトルから眼上軸を推定する逆計算です。実測に代わる精度を保証しません。

## ファイル

`app.py` が今回の変更を含む画面・推定・出力レイヤーです。`engine.py`、`optics.py`、`visuals.py` の既存の数値計算・グラフ関数を再利用しています。engine単体の既知回転APIは互換性のため維持し、アプリの推定モデル・出力はapp.pyで区別しています。
