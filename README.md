# Toric SCL Axis Planner — v0.3.0

日本語のStreamlitアプリ。教育・研究用の臨床未検証プロトタイプです。

**旧版からの更新は app.py と engine.py を一緒に差し替えます。**
[更新手順](START_HERE_JA.md) をお読みください。

| 欄 | S・Cリスト | Axリスト |
|---|---|---|
| 01 装用前 | 0.25 D | 5° |
| 02 SCL表示度数 | 0.25 D | 10° |
| 03 装用後 | 0.25 D | 5° |

数値リストは0始まりです。直接入力は範囲内の任意値に対応し、リストの刻みへ丸めません。デモの画面・読込機能は削除しました。04は次レンズの候補軸設定です。

回転は01−03から推定する前版の方式を維持します。推定の臨床的精度を保証しません。
