# 計算仕様 v0.1.0

## 1. 目的と単位

目的は、指定した次レンズS/Cと候補表示軸集合の下で、**角膜面の残余円柱度数の絶対値 |C| を最小化**することです。SとCを同時に最適化する処方計算ではなく、視力や快適性を目的関数にも用いません。

度数はD、軸と回転は度、頂点間距離の入力はmmです。内部の頂点間距離計算ではmへ換算します。軸は内部で[0,180)、表示は(0,180]とし、0°と180°を同一視します。数値ゼロの判定EPSは1e-10 Dです。臨床的無視可能性を意味する閾値ではありません。

SCLはマイナス円柱表記のみです。装用前・装用後の屈折値はプラス円柱表記にも対応し、必要に応じて S'=S+C、C'=−C、A'=A+90°で転置します。

## 2. 回転と観察視点

検者が患者の正面から見る視点に統一します。光学軸の数値は反時計回り方向に増加し、物理的回転rは時計回りを正とします。

```text
A_actual = (A_label − r_current) mod 180°
A_next_actual(a) = (a − r_next) mod 180°
```

目標眼上軸A_targetから求める注文表示軸は A_target+r_next です。これはCAASの時計回り加算・反時計回り減算に対応します。[2]

例：目標180°、時計回り20°なら表示軸20°。目標180°、反時計回り30°なら表示軸150°。

**左右眼で符号は反転しません。** 鼻側／耳側への回転は眼別の対応が必要になるため、本UIでは採用しません。

位置マークはレンズの基準からの回転量の測定に用います。位置マーク自体の子午線をそのまま光学軸として入力しないことを前提とします。6時マークは図の例であって、すべての製品に共通するマーク規格を示してはいません。

## 3. 測定面の統一

装用前の矯正値とSCL装用後の追加矯正値それぞれに対して、両主経線の屈折力F1=S、F2=S+Cを独立に換算します。

```text
眼鏡面 → 角膜面： Fc = Fs / (1 − d Fs)
角膜面 → 眼鏡面： Fs = Fc / (1 + d Fc)
```

この式は、薄レンズの焦点距離から距離dだけ基準面を移動すると有効焦点距離が1/F−dになることから導けます。Cだけを頂点間距離換算してSと足す処理はしません。各主経線の換算後にS/Cへ戻します。

入力は0〜25 mmの範囲、計算ライブラリの換算関数は0〜30 mmを受け付けます。分母が0以下になるケースは適用範囲外としてエラーにします。全度数で変換し、±4Dなどの閾値で変換の有無を切り替えません。

装用後追加矯正はレンズ装用下で測定した値であり、総処方を示す値ではありません。機器がすでに0 mmへ換算している場合は重複補正を避けるため0 mmとします。

## 4. パワーベクトル

Thibosの表現を使います。[1]

```text
M   = S + C/2
J0  = −(C/2) cos(2A)
J45 = −(C/2) sin(2A)
```

S/C/Axisへ戻すときは、マイナス円柱表記として次を使用します。

```text
C = −2 sqrt(J0² + J45²)
S = M − C/2
A = 0.5 atan2(J45, J0) mod 180°
```

Cが数値的に0の場合、軸はNoneです。表示上0.00 Dに丸められる極小乱視でも軸を強調せず、JSON/CSVには未丸め値を残します。

独立した検算では、子午線屈折力行列

```text
[[S + C sin²A, −C sin A cos A],
 [−C sin A cos A, S + C cos²A]]
```

の和と、パワーベクトルから得た結果の行列が一致することを確認します。

## 5. 必要矯正の再構成

現在のレンズの実際の眼上軸からL_actualを計算します。装用後の追加矯正を角膜面へ換算した値をO_cとすると、主計算の推定必要矯正Tは

```text
P_T = P_L_actual + P_O_c
```

です。これは**同じ角膜面に置いた薄レンズの屈折力の和**としてのモデルです。実際のSCLが理想的な薄い球面円柱レンズとして作用し、装用後測定と観察した回転量が同じ状態を表していることを仮定します。

**装用前の矯正R_cは、この式に重ねて加算しません。** 装用前＋SCL＋装用後を足すと必要矯正を二重計上します。

## 6. 残余乱視最小の表示軸

候補表示軸aについて次を評価します。

```text
P_res(a) = P_T − P_L_next(a − r_next)
|C_res(a)| = 2 sqrt(J0_res² + J45_res²)
```

次レンズのS/Cは固定です。マイナス円柱のベクトルは、軸変更でJ0/J45平面上の一定半径の円上を移動します。推定必要矯正のJベクトル方向と一致させたときに両者の距離が最小になるため、連続最適眼上軸はTの軸、連続最適表示軸はTの軸+r_nextです。

候補軸は列挙して評価します。数値誤差相当の同率の場合、現在の**表示軸**からの最短変更量が小さいもの、次に表示軸の小さいものを優先します。同率軸も出力します。これは同率の場合のUI上の順序づけであり、優れた臨床成績を示す優先順位ではありません。

次レンズのCが0、またはTのCが数値的に0の場合、残余|C|は軸によらず一定なので最適軸を1つに定めません。

## 7. 軸だけで取り除けない成分

連続軸の範囲での理論下限は

```text
min |C_res| = ||C_T| − |C_next||
```

です。したがって円柱度数が合わなければ、軸だけを変えても残余乱視はゼロになりません。

球面等価は

```text
M_res = M_T − (S_next + C_next/2)
```

です。S/Cを固定したまま軸を変更しても、このM_resは変わりません。残余S単独はC表記の変化で変動するため、残余Sと球面等価Mを混同しないよう別表示します。

## 8. 装用前との整合性

以下を別計算します。

```text
装用前から予測した現在の残余 = P_R_c − P_L_actual
必要矯正の不一致 = P_T − P_R_c
```

ΔMと、Jベクトル差を円柱度数に換算した2sqrt(ΔJ0²+ΔJ45²)を表示します。Cの単純な差ではありません。

初期の不一致警告閾値は0.50 D、設定可能範囲は0.05〜5 Dです。**臨床的に検証済みの合否基準ではなく、確認を促す便宜的な閾値です。** 閾値以下でも測定が妥当と保証されるわけではありません。装用前基準と装用後基準は自動で平均・重み付けしません。

## 9. 回転変動シナリオ

次の回転が r_next±h に変わったと仮定し、その範囲での残余|C|の最小値・最大値を計算します。端点に加えて、目標軸と平行／直交となる内部極値も評価するため、端点だけの近似ではありません。

この計算は**次レンズの回転のみを変化させ、現在の測定から再構成したTを固定**します。現在の回転量の測定誤差・他覚的屈折誤差を伝播させるものではありません。初期値±5°も例示的な設定で、信頼区間・予測区間ではありません。

## 10. 対象外と臨床的限界

正乱視に対する薄いSCLと近軸光学を想定します。不正乱視、高次収差、涙液変化、SCLによる角膜変形、偏心・傾斜、レンズの実効度数変化、瞳孔径、調節、測定ノイズ、経時回転はモデル化しません。RGP・オルソケラトロジー・IOL用ではありません。

同じ製品でも度数・軸・装用条件が変わると回転の再現性が変わり得ます。S/Cを変更できる詳細設定は仮想比較であって、次レンズの回転を予測する学習モデルではありません。

他覚値の使用では自覚的追加矯正と視力で再確認が必要です。安定しない回転は固定軸補正では解決できない可能性があります。表示結果は眼上レンズを手で回す指示ではなく、試験装用する別の表示軸の計算候補です。[2]
