# v0.2.0 計算仕様：実測回転入力を使わない逆モデル

本仕様は臨床未検証です。数学表現の文献がこのアプリの臨床妥当性を検証したものではありません。

## 入力と測定面

B：01の必要矯正、L：02のSCL表示度数、R：04のSCL装用下の追加矯正。

B、Rはそれぞれの頂点間距離を用い、SとS+Cの両主経線を `F_cornea=F_spectacle/(1-d*F_spectacle)` で角膜面へ換算します。Lは角膜面とします。これは薄レンズ・同一面近似です。

パワーベクトルは `P=(M,J0,J45)`、`M=S+C/2`、`J0=-C*cos(2A)/2`、`J45=-C*sin(2A)/2` です。[1]

## 回転の推定

`P_implied_lens = P_B - P_R`

このベクトルの乱視方向から、マイナス円柱としての眼上軸を推定します。

`A_eye = atan2(J45_implied, J0_implied)/2`（180°周期）

`r_est = signed_axis_difference(A_label, A_eye)`

検者が患者の正面から見て時計回り正、右眼・左眼で符号は反転せず、`A_eye=A_label-r_est` です。回転補正の符号はメーカー資料のCAASと対応します。[2]

**ここでr_estは観察した回転量ではなく屈折値からのモデル推定です。** ベクトル差が数値的にゼロなら方向を識別できません。現版は等価|C|が0.05 D未満でも推定を保留します。これは便宜的な不安定性ガードで、臨床的に確立した閾値ではありません。

## 入力値が厳密には整合しない場合

乱視ベクトル差の大きさは02の|C|と一致するとは限りません。そこで方向のみを使い、02のS/Cを推定眼上軸へ配置します。

`P_fitted_lens = P_L(A_eye)`

この操作は、固定円柱振幅のベクトルを、推定された乱視ベクトルの方向へ射影した最小二乗適合です。回転では調整できないM差と|C|差を表示します。

`delta_M = M_nominal - M_implied`

`delta_absC = abs(C_nominal) - abs(C_implied)`

いずれかの絶対値が設定閾値（初期0.50 D、未検証）を超える場合は、回転だけでは説明できないことを警告します。この比較は独立検証ではありません。01が推定自体に使われているためです。

## 次候補の評価

現在の残余測定を基準として、必要矯正を次のように再構成します。

`P_target = P_fitted_lens + P_R`

候補表示軸a、次の固定S/C、同じ推定回転r_estに対し、

`P_residual(a) = P_target - P_next(a - r_est)`

`abs(C_residual) = 2*sqrt(J0_residual^2 + J45_residual^2)`

が最小の候補を比較表示します。Bをここへさらに加算しません。屈折データが理想モデルと一致すればP_target=P_Bになります。R=0のときは、不要な二重補正を避け現在表示軸が維持されます（その表示軸が候補に含まれる場合）。

S/Cの変更は既存の詳細設定として残しますが、固定した回転挙動の再現を保証しません。|C|のみの最小化と残余Mは別に表示します。

## 限界

屈折状態が測定間で変化しないこと、SCL効果を薄レンズで近似できること、次のレンズでも推定回転が再現することが前提です。SCLの変形・偏心、角膜形状、涙液、高次収差、調節変化、測定誤差は分離して推定できません。独立した回転測定をなくすことで情報は減少しており、以前の既知回転モデルと同等の精度を主張しません。

回転変動シナリオは次レンズの仮想変動だけで、現在の屈折値からの推定誤差を伝播させていません。統計的な信頼区間ではありません。

## 実装と後方互換

逆モデル・入力検証・推定結果のラベル付けはapp.pyに集約しています。旧engineの既知回転APIは変更せず再利用します。JSONでは実測回転の入力フィールドを出力せず、`rotation_estimation` と `assumptions.rotation_was_measured=false` を記録します。出力の版はapp.pyが0.2.0に設定します。
